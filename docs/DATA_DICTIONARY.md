# Flutter Data Dictionary

This document describes the local models in `flutter_app/lib/main.dart`. It does not describe every entity in the native Kotlin Room schema; see [ARCHITECTURE.md](../ARCHITECTURE.md) for the native architecture.

## FarmerApplication

One farmer/farm application in the Flutter registry.

| Field | Type | Meaning |
|---|---|---|
| `id` | string | Stable application/farm-record ID; used to link related activities. |
| `farmerName` | string | Farmer/beneficiary name. |
| `contact` | string | Contact information entered by the staff user. |
| `farmName` | string | Farm or holding name. |
| `province` | string | Province. |
| `municipality` | string | Municipality or city. |
| `barangay` | string | Barangay/local area. |
| `area` | string | Farm area as entered, including units if supplied. |
| `landTenure` | string | Land tenure value selected/entered in the form. |
| `commodities` | string | Commodity list as entered in the form. |
| `status` | string | Application review status; missing legacy value defaults to `For Review`. |
| `reviewNotes` | string | Staff review notes. |
| `updatedAt` | string | Last-update timestamp generated by the client. |

## FarmActivity

One locally recorded farm activity linked to a farmer application.

| Field | Type | Meaning |
|---|---|---|
| `id` | string | Stable activity ID. |
| `farmRecordId` | string | Must match a farmer application's `id`. |
| `type` | string | One of `Crops`, `Livestock`, `Finance`, or `Tasks`. |
| `title` | string | Crop, animal, finance purpose, or task title. |
| `category` | string | Category label for the activity type. |
| `quantity` | string | Optional quantity/area value as entered. |
| `unit` | string | Optional unit such as ha, kg, or heads. |
| `amount` | number | Optional amount recorded in PHP. Zero means no amount was entered; it is not a price estimate. |
| `date` | string | Record date, intended format `YYYY-MM-DD`. |
| `status` | string | Status label chosen for this activity type. |
| `notes` | string | Optional notes. |
| `updatedAt` | string | Client timestamp for last update. |

## Backup JSON envelope

The full backup is JSON with these top-level fields:

| Field | Meaning |
|---|---|
| `format` | Must equal `agrivision.local-backup`. |
| `schemaVersion` | Currently `1`. |
| `app` | `AgriVision`. |
| `exportedAt` | Export timestamp in ISO 8601 format. |
| `recordCounts.farmers` | Farmer record count included in the export. |
| `recordCounts.activities` | Activity record count included in the export. |
| `farmers` | Array of `FarmerApplication` objects. |
| `activities` | Array of `FarmActivity` objects. |

The restore parser rejects unsupported format/version, malformed rows, missing farmer IDs/names, duplicate IDs, unknown activity types, orphaned activity references, invalid or negative amounts, and input larger than 10 MiB. Do not edit a backup to join records by names; stable IDs define relationships.

## Report exports

CSV and JSON report exports include only the current Flutter edition's local records. They are not a validated official DA submission format. The share sheet sends the selected report to the destination chosen by the user; the recipient may keep a separate copy.
